Lookbook MCP

Director's Lookbook as an MCP server. Describe a feeling and your AI client deals a matched look from the card library (shots, camera moves, light, film stocks, grades, palettes, type and music), then turns it into prompts you can paste into image, video and music tools.

Free. Read-only. No account or key needed.

Server URL

https://lookbook-mcp.riverroadlabs.workers.dev/mcp

Streamable HTTP. No authentication.

Add it to Claude

  1. Open Settings, then Connectors.
  2. Choose Add custom connector.
  3. Paste the server URL above and save.

Then ask, for example:

  • "Use the Lookbook to give me a look for a rainy cafe at night, then write the image and video prompts."
  • "Deal me a look for a moody product shot of a perfume bottle and write the Midjourney prompt."
  • "Give me a Suno style for a sad bedroom pop song about a 3 a.m. phone call."
  • "Pick a landing-page look for a dark developer tool and write the site prompt."

One-click install

Add to Cursor Add to VS Code

Claude Code, in a terminal:

claude mcp add --transport http directors-lookbook https://lookbook-mcp.riverroadlabs.workers.dev/mcp

Add it to another client

{
  "mcpServers": {
    "directors-lookbook": {
      "url": "https://lookbook-mcp.riverroadlabs.workers.dev/mcp"
    }
  }
}

Install with Smithery

The Lookbook is also listed on Smithery. With the Smithery CLI (Node.js 20 or later), one command adds it to your client:

npm install -g smithery@latest

# Cursor
smithery mcp add riverroadlabs/directors-lookbook --client cursor
# VS Code
smithery mcp add riverroadlabs/directors-lookbook --client vscode
# Windsurf
smithery mcp add riverroadlabs/directors-lookbook --client windsurf
# Claude Code
smithery mcp add riverroadlabs/directors-lookbook --client claude-code

Restart the client afterwards.

Installs through Smithery connect via Smithery's gateway, so Smithery handles those requests under its own terms. The direct server URL above reaches our server only.

Probing it from Python's standard library? Set a User-Agent header. Cloudflare blocks the default Python-urllib agent on workers.dev with error 1010; curl, requests and every MCP client pass.

Tools

All six tools are read-only.

ToolWhat it does
deal_handStart here. Deals one matched card per slot for a job (photo, video, site, game, song, cover) from a plain-language feeling. You can hold cards, set a subject, aspect ratio and shot count.
briefTurns card ids into paste-ready prompt blocks: image prompt, video prompt, palette hexes, type, Suno style and exclude lines, shot lists. Can format for Midjourney, Runway or Suno.
find_stylesSearches the cards by feeling, mood, era, technique or style name.
show_cardOne card in full: the prompt wording, what to avoid, moods, pairings, and links to its example image, clip or music sample.
lint_handChecks cards you combined yourself for clashes, such as black-and-white film with a colour grade.
list_suitsCard counts per suit and kind, to see what the library covers.

Prompts

Ready-made prompts your client can offer: look_for_a_scene, name_this_look, music_for_a_track, cover_art, game_key_art, product_reel.

Limits

About 60 requests a minute per connection, text inputs up to 300 characters, up to 12 card ids per call.

Privacy

The server does not log or store request content: no feeling, subject or other text you send. It keeps anonymous daily counts of the tools called, the job type, the app name your client reports and the cards it returned, plus a two-day salted hash used only to count distinct callers. It never stores your IP address. See the privacy policy.
