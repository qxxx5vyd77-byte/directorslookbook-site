Effective October 11, 2026. Director's Lookbook is made by River Road Labs.

Director's Lookbook has no accounts, no sign-up, no advertising cookies and no ad trackers. We never sell or share data for advertising. This page covers the website at directorslookbook.app and the Director's Lookbook MCP server at lookbook-mcp.riverroadlabs.workers.dev.

What the MCP server collects

The MCP server is read-only. It answers from a bundled card library and does not log or store the content of your requests: no feeling, subject or other text you send. For each call it keeps anonymous daily counts of the tool name, the job type if one was given (such as photo or video), the name your AI app reports for itself when it connects (such as "claude-ai" or "cursor") or the app family from its user agent, and the ids of the cards it returned. To count how many different callers use deal_hand and brief, it also makes a one-way hash of your IP address and user agent. That hash is hashed again with a random salt that changes every day and is deleted after two days, and the day's hashes are deleted after two days too, so they cannot be linked to an address or across days. We never store the IP address itself. It also counts, per day, which options were set, how calls follow one another within a session, whether a call matched, and a coarse subject category (person, product, food, scene, music, site or none) worked out in memory; the words themselves are never stored. Daily counts are kept for 400 days. It also keeps a short-lived count of requests per IP address in memory, to stop abuse. That count is never written to storage and disappears within minutes.

The MCP server is also listed on Smithery. If you install it through Smithery, your requests pass through Smithery's gateway before they reach our server. If you add the server URL directly, they reach our server only.

Who processes data for us

  • Cloudflare hosts the event counter (which also holds the MCP server's daily tool counts) and the MCP server, and runs Web Analytics and the AI model that reads a typed feeling.
  • Anthropic (the Claude API) reads a typed feeling only when Cloudflare's free AI allowance for the day is used up. It receives the feeling text and the job type, nothing else.
  • GitHub Pages serves the website, and may keep standard server logs.
  • Smithery relays MCP requests only for installs made through Smithery. Those requests pass through its gateway and are handled under Smithery's privacy policy. Direct installs do not touch Smithery.

Your choices

You can use every feature without typing a feeling: pick a ready look or build one card by card. Because we hold nothing that identifies you, we cannot look up or delete data for one person. If you typed something you want removed, email us the exact text and the date, and we will delete it.
