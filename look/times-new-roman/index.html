Times New Roman

Also called: Times, newspaper serif

Front page, final edition.

What it is

The 1932 newspaper serif: narrow, dense, sharp serifs, economical in a column. The look of print authority and of every default document.

The prompt

Paste it into an image prompt that renders text, or use the font itself for titles.

Prompt

Times New Roman lettering, narrow transitional newspaper serif, sharp bracketed serifs, dense black text in justified columns, print authority

Not this

What it gets confused with, or how it fails. Use it as a negative prompt where the tool takes one.

Not this

Not a book face: Times is narrow and brisk, not warm. Not a Didone either.
