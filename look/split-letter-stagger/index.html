Split-Letter Stagger

Also called: character stagger, text split animation

What it is

A word breaks into letters that rise and settle one after another with a little spring.

What it says: Personality in the type.

How it is usually built: one span per character with GSAP or a spring animation library

With reduced motion: Render the word in place.

The live demo runs in the Lookbook: open Split-Letter Stagger there.

The prompt

Paste it into a coding AI building the page.

Prompt

headline split into characters, each rising 40px with a slight rotation and a spring ease, 30ms stagger, played once when the headline comes into view

Not this

What it gets confused with, or how it fails. Use it as a negative prompt where the tool takes one.

Not this

Not a typewriter effect: letters move into place, they do not appear one by one.
