Evidence Wall Documentary

Also called: cork board documentary, red string investigation wall, true crime pin board, code-built documentary

What it is

One continuous camera glides over a single cork wall of pinned archive prints, torn clippings, typed letters and a route map, tied with red string; stamps slam, highlighters swipe and counters roll up on the narrator's word.

The prompt

Paste it into an image or video prompt as is, then add your own subject.

Prompt

documentary evidence wall, cork board of pinned black and white archive prints, torn newspaper clippings and a typed letter, red string between brass pushpins, a route map, red rubber stamp, yellow highlighter swipe, spotlight on one print

Not this

What it gets confused with, or how it fails. Use it as a negative prompt where the tool takes one.

Not this

Not a halftone pop-art case file, not a detective film still with actors, not a clean flat explainer. Real paper on real cork, one wall, one moving camera.
