Vaporwave

Also called: vapor art, 90s computer nostalgia, pastel grid sunset

What it is

Internet-era collage: pastel pink and cyan gradients, a wireframe grid floor, a striped sunset, marble busts, palm trees, old OS windows and katakana.

The prompt

Paste it into an image or video prompt as is, then add your own subject.

Prompt

vaporwave collage, pastel pink to cyan gradient sky, magenta wireframe grid floor, striped setting sun, marble bust, palm trees, early desktop OS window, katakana text accents

Not this

What it gets confused with, or how it fails. Use it as a negative prompt where the tool takes one.

Not this

Synthwave. Vaporwave is pastel and ironic, built from collage and old computer UI, not neon chrome on black.
