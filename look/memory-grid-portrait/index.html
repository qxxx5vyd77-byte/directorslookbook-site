Memory Grid Portrait

Also called: tile grid portrait, fragment memory poster

What it is

A grainy black-and-white close portrait cut into a square tile grid; some tiles drop out, others swap in small colour snapshots; a heavy condensed title low left.

The prompt

Paste it into an image or video prompt as is, then add your own subject.

Prompt

black and white close-up portrait cut into a square tile grid on cream paper, some tiles missing, a few tiles replaced by small colour snapshots of rooms and hands, one hot pink tile, heavy condensed title space lower left

Not this

What it gets confused with, or how it fails. Use it as a negative prompt where the tool takes one.

Not this

Not a photo mosaic: the tiles are big, the face reads at once, and the colour tiles are memories, not pixels.
