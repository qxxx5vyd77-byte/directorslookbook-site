Glassmorphism

Also called: frosted glass panels, translucent cards

What it is

Frosted translucent panels float over blurred colour: thin light borders, soft shadows, content reads through the glass.

What it says: Lightness with depth.

How it is usually built: CSS backdrop-filter with a solid fallback

With reduced motion: No change needed; keep blur off on low-power devices.

The live demo runs in the Lookbook: open Glassmorphism there.

The prompt

Paste it into a coding AI building the page.

Prompt

glassmorphism UI: translucent panels with backdrop blur, a 1px light border, soft drop shadows, over a blurred colour gradient; text stays high contrast on the glass

Not this

What it gets confused with, or how it fails. Use it as a negative prompt where the tool takes one.

Not this

Not flat transparency: the blur and the thin highlight edge make it glass.
