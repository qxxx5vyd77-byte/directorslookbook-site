Halftone Blur-Type Poster

Also called: CMYK dot poster, blurred type poster, form study poster

What it is

One isolated object printed in coarse CMYK halftone dots on a hot yellow-to-red gradient, with huge soft-focus cream lettering above and below it, as if the type is out of focus behind glass.

The prompt

Paste it into an image or video prompt as is, then add your own subject.

Prompt

single object in coarse CMYK halftone dot print, isolated on a hot yellow to red gradient background, huge blurred soft-focus cream type space above and below, slight misregistration, warm paper grain, poster layout

Not this

What it gets confused with, or how it fails. Use it as a negative prompt where the tool takes one.

Not this

Not a crisp Swiss poster: the type is deliberately blurred and the object is all visible dots, never a smooth photo.
