60s Spy Title Sequence

Also called: 1960s title sequence, cut-paper opening titles, mid-century movie titles

What it is

A four-ink cut-paper title sequence: profile silhouettes run through sets built from the credits, each brass stab is a cut, and the pieces assemble into the title.

The prompt

Paste it into an image or video prompt as is, then add your own subject.

Prompt

1960s cut-paper title sequence, four flat opaque inks (black, cream, red, mustard), hand-cut paper edges with small shadows, profile silhouette figure, credits as architecture, bold diagonals, giant red circle

Not this

What it gets confused with, or how it fails. Use it as a negative prompt where the tool takes one.

Not this

Not flat vector motion graphics, not a halftone print, not a strict Swiss grid, not a spy parody with gadgets.
